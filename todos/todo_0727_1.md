# TODO: AlphaZero Endgame Validation - 2026-07-27

## Requirement Description

Add a small, GPU-enabled AlphaZero-style training experiment to `chess_refactor` without modifying the commemorative parent-directory source files.

The first version is limited to fixed legal endgame positions containing both generals and a red rook. Its goal is to verify the complete training loop, rather than to build a strong full-game Chinese-chess engine.

The implementation must use the refactored `xiangqi` rule engine for legal moves, move application, check detection, terminal-state detection, and repetition handling. It must not reuse the parent-directory `alphazero.m` search or data-accumulation logic.

## Implementation Plan

Create a separate `+alphazero` package that adapts the existing rules to an AlphaZero-style pipeline. Use a small policy-value network, fixed action encoding, legal-action masking, PUCT Monte Carlo tree search, bounded replay data, GPU training, and deterministic candidate evaluation.

The policy maps one board state to scores for all `90 x 90 = 8100` source-target actions. The value estimates the outcome from the current player's perspective. MCTS visit counts provide policy labels, and game outcomes provide value labels.
