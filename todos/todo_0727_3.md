# TODO: Unified Full-Game AlphaZero Training - 2026-07-27

## Requirement Description

Train one unified AlphaZero policy-value model from the standard Chinese-chess opening position. The final model must support both normal full-game play and curated endgame challenges.

The project will maintain exactly one formal checkpoint at `chess_refactor/models/best_model.mat`. The current small endgame-validation checkpoint may be overwritten when the new full-game network is initialized. There will be no separate endgame model after this work begins.

Training must remain resumable across separate sessions. A user can stop after a bounded segment and continue later without losing the best model, replay data, progress counter, training logs, or checkpoint provenance.

## Assumptions

- Full-game training starts from `xiangqi.new_board()` with red to move.
- Initial draw adjudication uses the implemented threefold-repetition rule and a configurable maximum-ply limit. Formal long-check and long-chase adjudication remain out of scope until separately implemented and tested.
- The unified model initially trains on full-game self-play only. Curated endgame scenarios return later as a controlled mixture after the full-game pipeline is stable.
- `models/best_model.mat` becomes the only model path used by both `run_gui` and `run_endgame_challenge`.
- The existing endgame validation code and curated scenarios remain available as regression fixtures and later training data, but are not the initial full-game training distribution.

## Implementation Plan

Replace the validation-scale network with a board-position-preserving residual policy-value network and isolate full-game artifacts from prior validation replay chunks. Add full-game scenarios, resumable segment state, persistent per-iteration logs, opening-position evaluation, and measured training presets. Verify the full-game loop at small scale before starting longer GPU segments. Once a full-game checkpoint is accepted, use it as the shared model for normal GUI AI and endgame challenges.

## Acceptance Criteria

- `models/best_model.mat` is the sole formal model checkpoint for normal play and endgame challenges.
- The full-game network preserves board-position information and is incompatible with the old validation architecture by design.
- Standard-opening self-play uses only legal moves and terminates using the configured repetition and maximum-ply rules.
- Training can resume over multiple sessions with uninterrupted iteration numbering, replay chunk numbering, and append-only metrics logs.
- Small GPU smoke training completes with finite losses, bounded storage, valid evaluation output, and a recoverable checkpoint.
- The normal-game GUI and endgame challenge use the same accepted model after unified GUI adoption.
- Curated endgames are added as a measured training mixture only after full-game self-play is stable.
